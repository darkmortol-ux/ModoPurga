# ModoPurga
1. Sube todo a GitHub (carpeta `.github` incluida).
2. Pestaña Actions -> espera el check verde -> descarga el Artifact `ModoPurga`.
3. Pon `ModoPurga.jar` en `plugins/`, inicia el servidor y edita `plugins/ModoPurga/config.yml`
   (`enabled: true`, `event-world: "tu_mundo"`), luego `/purga reload`.
Comandos: /purga salir|leave|status (todos) y start|stop|reload (permiso modopurga.admin).
